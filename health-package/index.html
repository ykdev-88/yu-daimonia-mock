健康パッケージ

Health Package

あなたに合った健康プログラムを、カウンセリングを通じてご提案します。

概要・提供価値

日々の不調や体質の悩み、将来の健康不安など、一人ひとりの状態に合わせた健康づくりをサポートするプログラムです。分析・カウンセリング・温活を組み合わせ、無理のない継続を目指します。

提供価値①

現状把握と目標設定を丁寧に行います。

提供価値②

店舗の機器・サービスを活かした多角的アプローチ。

提供価値③

日常に取り入れやすい習慣づくりを伴走します。

PLAN

プラン・料金

あなたの目的に合わせて、3つのプランからお選びいただけます。

巡りプランDiet Line

こんな方におすすめ：体型や代謝の変化が気になる方

¥00,000 / 3ヶ月

食事や生活習慣の見直しと、温活によるめぐりサポートを組み合わせた、リバウンドしにくい体づくりプランです。カウンセリングであなたの生活リズムに合った無理のない目標を設定し、よもぎ蒸しなどで内側からのめぐりを後押しします。

  • 体質・生活習慣カウンセリング
  • 代謝サポートサプリ／酵素ドリンク
  • よもぎ蒸し定期利用チケット
  • 食事ログ・進捗フィードバック
このプランで申し込む

艶肌プランBeauty Line

こんな方におすすめ：肌・髪のコンディションを整えたい方

¥00,000 / 3ヶ月

肌や髪のコンディションを内側から整える美容特化プランです。温活で巡りを促しながら、美容系サプリメントやセルフケア指導で、年齢に左右されない自分らしい美しさをサポートします。

  • 美容カウンセリング（肌質・体質チェック）
  • 美容系サプリ（コラーゲン・酵素など）
  • よもぎ蒸し（美肌・巡りコース）
  • スキンケア／セルフケアアドバイス
このプランで申し込む

土台プランWellness Line

こんな方におすすめ：不調知らずの毎日を目指したい方

¥00,000 / 3ヶ月

日々のちょっとした不調や、将来の健康への漠然とした不安に向き合う総合ケアプランです。分析・カウンセリングをもとに、温活や生活習慣の見直しを組み合わせ、心身ともに整った毎日の土台をつくります。

  • 健康状態カウンセリング・簡易分析
  • 基礎サプリ（栄養バランス系）
  • よもぎ蒸し（リラックス・体質改善コース）
  • 生活習慣の振り返り・継続サポート
